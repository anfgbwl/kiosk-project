# 학교 태양광 에너지 키오스크

1080 × 1920 고정 세로형 HTML 애플리케이션. 주간·야간은 하나의 페이지 안에서 일출·일몰 시각에 따라 바뀝니다. 다른 화면 비율에서는 전체 아트보드를 같은 비율로 축소하고 남는 공간을 어둡게 표시합니다. 터치 버튼, 메뉴, 스크롤, 슬라이드는 없습니다.

## 실행

1. ZIP을 로컬 폴더에 전부 풉니다.
2. `dist/index.html`을 Chrome 또는 Edge로 엽니다. 설치 및 인터넷 연결이 필요하지 않습니다. F11 전체 화면으로 표시합니다.
3. 첫 실행은 실제 데이터 수신 대기입니다. 값이 없으면 `—`와 데이터 없음 상태를 표시합니다.
4. 검수는 주소 끝에 `?demo=1&mode=day` 또는 `?demo=1&mode=night`를 붙입니다. 두 주소는 같은 애플리케이션의 강제 모드 설정입니다. 화면 내 이동 버튼은 없습니다.
5. 자동 전환 검수는 `?demo=1`만 붙이고, 실제 운영은 모든 검색 매개변수를 제거합니다.

Node.js가 설치되어 있으면 프로젝트 폴더에서 `node serve.cjs`로 실행 후 `http://127.0.0.1:4173/`에 접속할 수도 있습니다. 네트워크 방화벽이나 로컬 브라우저 정책에 따라 로컬 서버 접근 허용이 필요할 수 있습니다.

## 현장 설정

`dist/config.js`의 학교명, 설치용량, 위도·경도를 수정합니다. 현재 위치는 **부산 대표 좌표(35.1796, 129.0756)**이며 실제 학교 좌표가 아닙니다. 설치용량 100 kW도 검수 설정값입니다. 현장 인수 시 반드시 교체합니다. 한국시간은 운영 PC의 시계를 기준으로 `Asia/Seoul`에 맞춰 표시합니다. PC 시계가 틀리면 화면 시각과 자동 전환에도 영향이 있습니다.

`dataMode: 'live'`가 기본입니다. `demo` 모드의 발전량·출력·환경값은 합성 데이터이며 화면에 **검수용 예시 데이터**를 표시합니다. 이 표시는 운영 모드에 나타나지 않습니다. 예시 데이터는 1분마다 새로 만들어지며, 데이터 시각과 현재 시각은 분리되어 있습니다. 현재 출력 곡선의 사다리꼴 적분값을 오늘 발전량으로 사용합니다. 아직 오지 않은 시각의 출력은 그래프에 그리지 않습니다.

## 데이터 연결

실제 모니터링 API와 저장 기능은 포함되지 않았습니다. 현장 수집 어댑터가 **실제 수신한 객체**로 `window.kiosk.receive(snapshot)`을 호출하도록 연결합니다. 화면의 모드 전환은 수집·저장 설정을 바꾸거나 수집 작업을 중지하지 않습니다.

```javascript
window.kiosk.receive({
  schoolName: '푸른빛중학교',
  currentPowerKw: 56.7,
  todayEnergyKwh: 328.4,
  totalEnergyKwh: 215680,
  capacityKw: 100,
  irradianceWm2: 771,
  temperatureC: 24.6,
  carbonReductionTons: 98.1,
  energyDate: '2026-11-09', // 한국시간 집계일
  trend: [ // 해당 날짜의 실제 관측값 전체. at 오름차순 권장
    { at: '2026-11-09T13:15:00+09:00', kw: 57.2 },
    { at: '2026-11-09T13:24:00+09:00', kw: 56.7 }
  ],
  measuredAt: '2026-11-09T13:24:00+09:00', // 실제 계측 기준 시각
  connected: true,
  lastCheckedAt: '2026-11-09T13:24:12+09:00' // 실제 통신 확인 시각
});
```

위 객체는 스키마 설명용입니다. 실제 그래프 전체와 오늘 발전량을 현장 시스템에서 일치시켜 공급해야 합니다. 탄소 저감 효과는 원본 시안에 있는 항목이므로 유지하며, 변환 계수와 계산은 현장 시스템에서 결정합니다. 누적 발전량·탄소 저감값은 마지막 유효 계측값을 유지하고, 현재 출력·일사량·온도는 오래되었거나 끊긴 경우 숨깁니다. 오늘 발전량은 같은 날짜의 마지막 수신값을 보존하되 주간 하단에 상태를 표시합니다.

통신 상태만 새로 확인했다면 `window.kiosk.heartbeat(true, 실제확인시각)`을 호출합니다. 연결 실패 시 `false`를 전달합니다. 하트비트 호출은 계측 기준 시각을 갱신하지 않습니다. 데이터 기준 시각을 현재 시각으로 대신 채우지 않습니다. 5분 이상 계측 지연 시 갱신 지연, 2분 이상 통신 확인이 없으면 연결 끊김으로 처리합니다. 기준은 `config.js`에서 조정할 수 있습니다. 자정 이후에는 전날 오늘 발전량과 그래프를 비워 오표시를 방지합니다.

## 일출·일몰

SunCalc 1.9.0을 로컬에 포함했습니다. 계산은 오프라인으로 진행하며 외부 API를 호출하지 않습니다. 다음 일출은 새벽에는 당일, 일출 이후에는 다음날입니다. 시스템이 시간을 제공하면 `window.kiosk.setSolarTimes('2026-11-09', {sunrise:'2026-11-09T06:51:00+09:00', sunset:'2026-11-09T17:23:00+09:00'})`로 날짜별 값을 전달합니다. 공급된 유효 값이 계산보다 우선합니다. 실제 지평선·주변 건물과 대기 상태에 따른 관측 차이가 있을 수 있습니다.

개발자 콘솔의 `window.kiosk.setModeForTest('day')`, `('night')`, `(null)`로 화면을 각각 강제/자동 모드로 확인할 수 있습니다. `window.kiosk.inspect()`는 현재 데이터와 모드를 반환합니다. 운영 화면에는 검수용 제어 UI가 없습니다.

## 디자인 및 원본

- `dist/styles.css`: 공통 컬러·폰트·카드 토큰 및 1080×1920 좌표.
- `dist/assets/NotoSansKR-VF.ttf`: Noto Sans KR 단일 가변 폰트. 모든 문자·숫자에 사용. OFL 라이선스 동봉.
- `dist/assets/busan-education-white.svg`, `hanbit-white.svg`: 제공한 화이트 원본 SVG를 변경 없이 복사. 어두운 화면에 투명 배경으로 배치하며 로고 주변 안전 여백 유지.
- `approved-day.png`, `approved-night.png`: 제공한 확정 시안 원본. CSS로 학교 건물·잎·수면 캐릭터 영역만 보여줍니다. 화면 전체를 배경으로 사용하지 않으며 제목, 수치, 카드, 그래프는 HTML/CSS/SVG입니다.
- 주간: 원래 카드/그래프/홍보 영역 유지. 요청된 설치용량·일사량·온도는 그래프 상단에 작은 한 줄로 배치.
- 야간: 원본 캐릭터, 달·별·수면 표현 유지. 내부 운영 문구를 넣지 않고 연결 상태와 마지막 확인만 표시.

## 테스트 및 재배포

`node tests/core.test.cjs`로 날짜 경계, 일출·일몰, 단위/수치 유효성, 데이터 지연, 연결 끊김, 예시 그래프 적분을 확인합니다. `tests/render.cjs`는 Playwright가 설치된 개발 환경에서 PNG를 생성하는 참고 스크립트입니다. 경로 설정은 해당 PC에 맞춰 조정합니다.

정적 호스팅에는 `dist` 폴더 내용만 업로드합니다. Netlify 수동 배포에서 `dist`를 드래그하거나, Vercel에서 정적 프로젝트로 지정해 출력 폴더를 `dist`, 빌드 명령을 없음으로 설정합니다. 서비스 가입/로그인은 해당 계정 소유자가 진행합니다. 실제 배포 주소는 `DELIVERY.md`에 기재합니다. 로컬 운영과 외부 검수 데이터는 서로 연결되지 않습니다.

외부 의존 출처: [SunCalc](https://github.com/mourner/suncalc/tree/v1.9.0), [Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr). 실행 시 이 사이트에 접속하지 않습니다.
