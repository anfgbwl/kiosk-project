# 최종 납품 및 검수 보고

작성일: 2026-11-09 (한국시간)

## 외부 미리보기

- [주간 검수](https://hanbit-school-solar-kiosk.sappyblade.chatgpt.site/?demo=1&mode=day)
- [야간 검수](https://hanbit-school-solar-kiosk.sappyblade.chatgpt.site/?demo=1&mode=night)

외부 인터넷에서 로그인 없이 접속하도록 공개 배포했습니다. 위 주소는 실제 배포 성공을 확인한 주소입니다. 모두 동일한 index.html 애플리케이션이며 mode는 개발 검수용 강제 표시 설정입니다. 실제 화면에는 모드 이동 버튼이나 메뉴가 없습니다.

배포 버전: 3 (화이트 로고 교체).

## 최종 이미지와 파일

- `deliverables/kiosk_day_final.png`: 주간 1080 × 1920
- `deliverables/kiosk_night_final.png`: 야간 1080 × 1920
- `dist/`: 오프라인 실행용 HTML, CSS, JavaScript, 원본 SVG, 원본 그래픽, 로컬 폰트, 일출·일몰 계산 라이브러리 및 라이선스
- `README.md`: 실행, 설치, 데이터 연결, 날짜/연결 상태, 정적 호스팅 방법
- `tests/core.test.cjs`: 날짜 및 데이터 처리 자동 검사
- `serve.cjs`: 선택 사항인 로컬 정적 서버

최종 PNG는 배포된 실제 HTML을 1080 × 1920 브라우저 화면으로 렌더링하여 저장했습니다. 브라우저 캡처 도구가 반환한 JPEG를 같은 해상도의 PNG로 변환했으며 레이아웃/문자/수치 보정이나 합성은 하지 않았습니다. 이미지 수치는 촬영 시점의 검수용 데이터입니다. 미리보기의 수치와 시각은 계속 변합니다.

## 확정 시안 대비 반영 사항

1. 전체 정보 배치, 네이비 배경, 민트/그린 포인트, 둥근 카드, 면적 그래프, 홍보 문구를 유지했습니다. CSS로 재현한 배경과 카드 효과는 원본 래스터 시안과 미세한 차이가 있을 수 있습니다.
2. 학교 건물·잎·야간 캐릭터는 원본 이미지 영역을 그대로 사용했습니다. 그림이 들어가는 영역만 CSS로 노출하고 경계를 부드럽게 연결했습니다. 제목·문구·수치·그래프를 원본 이미지의 문자로 대체하지 않았습니다.
3. Noto Sans KR 단일 폰트를 로컬에 포함하고 굵기·크기로 위계를 구분했습니다.
4. 우측 상단을 현재 한국 날짜·시각으로 교체했습니다. 주간·야간의 위치와 크기는 같습니다.
5. 추가 제공된 교육청·한빛 화이트 SVG를 수정 없이 삽입했습니다. 흰색 배경판을 제거하고 투명 배경과 안전 여백을 적용했습니다. 주간은 하단 왼쪽, 야간은 하단 가운데입니다.
6. 주간 하단 오른쪽에 실제 공급 데이터의 계측 기준 시각과 지연/연결 상태를 분리 표시했습니다.
7. 원본 시안의 탄소 저감 효과를 유지했습니다. 요청에 있으나 첨부 이미지에 별도 칸이 없던 설치용량·일사량·온도는 그래프 상단의 보조 정보 행에 배치했습니다.
8. 그래프는 실제 수신 시각까지만 표시합니다. 원본 시안처럼 미래 시간대의 출력을 관측값으로 표시하지 않습니다. 검수용 오늘 발전량은 같은 곡선의 적분값입니다.
9. 야간의 내부 운영 문구를 제거하고 연결 상태·마지막 확인을 표시했습니다. 날짜가 바뀌면 전날 발전량을 오늘 값으로 재사용하지 않습니다.
10. 외부 검수 화면에는 ‘검수용 예시 데이터’를 명시했습니다. 실제 운영 모드에는 이 표시가 없습니다.

## 실제 연동 및 남은 현장 확인

- **실제 계측 API, 통신 어댑터 및 수집·저장 시스템은 미연동**입니다. 함수 연결 지점과 예시 데이터만 제공됩니다. 검수 화면의 연결됨은 합성 공급자의 상태입니다.
- 실제 학교명, 학교 좌표, 설치용량, 탄소 환산 방식과 계측 단위는 현장 값으로 확정해야 합니다. 현재 부산 대표 좌표와 100 kW 설정은 예시입니다.
- 폰트·이미지·CSS·JavaScript·일출 계산 파일을 전부 로컬에 포함했고 실행 중 CDN/외부 API를 호출하는 코드가 없습니다. 다만 이번 작업 환경의 브라우저 접근 제약으로 **file:// 직접 실행 및 인터넷을 끊은 현장 PC 실행은 실제 브라우저로 검증하지 못했습니다.** 현장 PC에서 ZIP을 풀어 직접 실행하는 확인이 남아 있습니다. 온라인 배포 화면은 실제 브라우저에서 검수했습니다.
- 원본에는 별도의 편집 가능한 일러스트가 없어 제공된 래스터 시안의 그래픽 영역을 활용했습니다. 전용 원본 에셋이 추후 제공되면 동일 배치에서 대체할 수 있습니다.
- 현장 PC의 전체 화면 자동 시작, 전원 복구, OS 시각 동기화, 데이터 저장 정책은 해당 현장 운영 구성에 포함해야 합니다.

미리보기는 UI 검수용 공개 사이트이며 실제 현장 데이터나 내부 시스템과 연결되어 있지 않습니다.
